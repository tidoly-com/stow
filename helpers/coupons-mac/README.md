# 쿠폰 도우미 (맥)

그림 하나를 받아 바코드를 찾고, 바코드가 있으면 글자를 읽어 돌려준다. 바코드 찾기와 글자 읽기 모두 macOS 의 Vision 이다 — 함께 내보낼 것이 없다. 맥만 지원한다(운영자, 2026-10-14).
쿠폰인지(유효기간이 있는지)는 서버가 가린다. 주고받는 꼴은 `main.swift` 머리에 있다.

```
./build.sh            # → ./stow-coupons
echo '{"picture":"/path/to/a.png"}' | ./stow-coupons
```
