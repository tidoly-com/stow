# 쿠폰 도우미 (맥)

그림 하나를 받아 그 안의 글자를 읽어 돌려준다. 글자 읽기는 macOS 의 Vision(한국어 · 영어)이라 함께 내보낼 것이 없다. 맥에서만 돈다.

바코드는 서버가 직접 읽는다(`internal/coupons`, gozxing — 맥 · 윈도 · 리눅스 모두). 서버는 바코드가 읽힌 그림만 이 도우미에 보내고, 돌아온 글자에서 유효기간을 찾는다. 이 도우미가 없으면 쿠폰 앨범은 그대로 모이고, 유효기간만 "모름" 으로 남는다.

서버가 띄우고, 표준 입출력으로 한 줄에 JSON 하나씩 주고받는다. 꼴은 `main.swift` 머리에 있다.

```
./build.sh            # → ./stow-coupons
echo '{"picture":"/path/to/a.png"}' | ./stow-coupons
```

사진 1만 4천 장의 폴더에서 바코드가 두 번 읽힌 68장 가운데 30장의 유효기간을 읽었다(2026-10-14). 쿠폰을 거르는 기준과 잰 숫자는 `docs/barcodes-and-faces.md`.
